# Research Tools

Маркетплейс навичок для UX-дослідників. Він перетворює дані дослідження на висновки, які можна обґрунтувати: правильна метрика, перевірена на ваших даних і пояснена простою мовою разом із невизначеністю.

Працює як маркетплейс **Claude Code** і як плагін **Codex**. 🇬🇧 [English version](README.md)

## Що всередині

У маркетплейсі один плагін — **`uxr`**.

| Навичка | Що робить |
|---|---|
| [`/uxr:sum`](guides/sum.ua.md) | **Єдина метрика зручності (SUM).** Об'єднує частку успішного виконання, час на завдання, задоволеність і, за бажанням, помилки в одну оцінку. Автопілот обирає варіант SUM, який підходить до ваших даних і мети. Ви отримуєте HTML-звіт і PDF «Як зрозуміти ваші результати», написаний простою мовою. |

Заплановано інші навички: довірчі інтервали для метрик завдань, порівняння дизайнів, підрахунок SUS, планування розміру вибірки та синтез знахідок.

## Встановлення

### Claude Code

```bash
claude plugin marketplace add vadym-shliachkov/research-tools
```

```bash
claude plugin install uxr@research-tools
```

У сесії те саме робить `/plugin marketplace add vadym-shliachkov/research-tools`. Після цього навички запускаються як `/uxr:sum`.

### Codex

```bash
codex plugin marketplace add vadym-shliachkov/research-tools
```

Потім увімкніть `uxr` з маркетплейсу `research-tools` у списку плагінів Codex. Або додайте до `.codex/config.toml`:

```toml
[plugins."uxr@research-tools"]
enabled = true
```

У Codex просто попросіть словами: «порахуй SUM для results.xlsx».

## Вимоги

- **Node.js 20 або новіший.** Інших залежностей у скриптів немає, нічого не встановлюється.
- **Chrome, Edge або Chromium** для PDF. Без браузера ви отримаєте той самий документ у HTML. Якщо браузер стоїть у нестандартному місці, задайте `CHROME_PATH`.

## Швидкий старт

```text
/uxr:sum results.xlsx
/uxr:sum results.xlsx --method pearson --ua
/uxr:sum results.csv --compare-methods
/uxr:sum results.csv --explain-choice
```

Навичка читає ваш файл і питає, що означає кожна колонка, замість того щоб вгадувати. До будь-яких розрахунків вона узгоджує з вами цілі, а потім записує все в `uxr-results/<дослідження>-<дата>/` поруч із файлом даних (або в робочу теку, якщо дані вставлено в чат чи передано посиланням). Повний опис — у [посібнику з SUM](guides/sum.ua.md).

## Мови

- Сам плагін (інструкції, довідники, скрипти) — англійською.
- Кожен документ для людей має українського двійника: [README.ua.md](README.ua.md), [guides/sum.ua.md](guides/sum.ua.md), [CHANGELOG.ua.md](CHANGELOG.ua.md).
- Підсумок у чаті надходить мовою, якою ви пишете. PDF із поясненням завжди створюється англійською; додайте `--ua` або попросіть українську версію, щоб отримати ще й український PDF і звіт.

## Словник термінів

| Термін | Що означає в цих документах |
|---|---|
| SUM | Єдина метрика зручності: одна оцінка, що поєднує кілька показників зручності |
| Складова | Один показник усередині SUM: частка успішного виконання, час на завдання, задоволеність або помилки |
| Ціль | Рівень, який команда домовилася вважати добрим; його фіксують до перегляду результатів |
| Діапазон | Довірчий інтервал 95%: проміжок, у якому найімовірніше лежить справжнє значення |
| Контракт вимірювання | Записаний перелік цілей і правил, збережений до розрахунку |
| Пресет | Іменований варіант SUM, наприклад `sum3` або `pearson` |

## Розробка

```bash
npm test
```

```bash
npm run check
```

- `plugins/uxr/` — плагін. У `scripts/` лежить спільний код для зчитування даних, статистики, перевірки читабельності та PDF; у `skills/<назва>/` — кожна навичка; в `agents/` — агент-редактор, який переписує тексти простою мовою.
- `tests/` — набори тестів `node --test`. Еталонні числа взято з наукових публікацій.
- `tools/check.mjs` стежить, щоб маніфести Claude і Codex збігалися, перевіряє frontmatter кожної навички (опис не довший за 1024 символи) і вимагає для кожного документа двійника `.ua.md` з тими самими заголовками.
- Нові навички працюють за тією самою схемою: зчитування даних → контракт вимірювання → детермінований скрипт → перевірки якості → висновок із невизначеністю. Спершу пишіть тести, а український двійник кожного документа додавайте в тому самому коміті.
